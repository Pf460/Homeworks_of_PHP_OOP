# Этот репозиторий создан для того чтобы предоставить доступ к выполненным домашним работам курсов PHP

---

## Cтек

---
- PHP 8.4-slim
- Docker Desktop
---

## Запуск программы
---

- Переходим в папку deploy/ из корня директории
````bash
cd deploy
````
- Собираем командой
````bash
docker compose up -d --build
````
- Дальнейшая навигация по веткам репозитория
---
## Важный нюанс

Пути к php файлам 
http://localhost:8080/<уровень-проверки>/<дальнейшая-директория(при наличии)>/<проверяемый-файл>
